Hướng dẫn kết nối nhanh cho AI Agent (REST API / URL / CLI)

1. Tải toàn bộ Kênh Facebook / Instagram / YouTube (HTTP POST)
POST http://127.0.0.1:6031/api/v1/reels/auto-download
{"url": "https://www.facebook.com/samfamily.6826/", "preferQuality": "1080p", "maxReels": 0}
2. Lưu Kênh Yêu Thích & Tự động quét hàng ngày (HTTP POST)
POST http://127.0.0.1:6031/api/v1/reels/favorites
{"url": "https://www.youtube.com/@YouTube/shorts", "checkIntervalMinutes": 1440, "scanNow": true}
3. Kích hoạt qua trình duyệt hoặc dòng lệnh CLI
http://127.0.0.1:6031/reels/?url=https://www.facebook.com/samfamily.6826/&auto=1
npm run download-page -- "https://www.instagram.com/instagram/reels/" --favorite
